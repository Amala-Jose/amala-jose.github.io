# Amala Jose — GitHub Pages Portfolio

A static personal portfolio website for Amala Jose, built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `Amala_Jose_Resume.pdf` — resume used by the Download Resume buttons

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. Your site will be available at `https://YOUR_USERNAME.github.io/`.

## Before publishing

Replace the placeholder LinkedIn `href="#"` in `index.html` with your actual LinkedIn profile URL.

The site intentionally has no backend, database, API, CMS, contact form or authentication.
